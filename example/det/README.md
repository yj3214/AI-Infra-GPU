# Detector 示例性能测试报告

## 1. 测试说明

本文档记录 `example/det` 检测示例在 YOLOv8 系列模型上的推理性能表现。

测试输入尺寸统一为：

| 参数 | 值 |
| --- | --- |
| 输入高度 | `640` |
| 输入宽度 | `640` |
| Batch Size | `1` |

性能指标说明：

| 指标 | 含义 |
| --- | --- |
| 平均推理耗时 | 单张图片端到端推理平均耗时，单位为 `ms` |
| FPS | 按平均推理耗时换算得到的吞吐率，计算方式为 `1000 / 平均推理耗时(ms)` |

> 注：性能数据来自 `example/det` 示例程序输出结果，主要用于不同模型和精度模式之间的相对性能对比。

## 2. FP32 性能结果

| 模型 | 输入尺寸 | 平均推理耗时 | FPS |
| --- | --- | ---: | ---: |
| YOLOv8n | `640 x 640` | `2.6 ms` | `387` |
| YOLOv8s | `640 x 640` | `3.3 ms` | `300` |
| YOLOv8m | `640 x 640` | `4.9 ms` | `204` |

## 3. FP16 性能结果

| 模型 | 输入尺寸 | 平均推理耗时 | FPS |
| --- | --- | ---: | ---: |
| YOLOv8n | `640 x 640` | `2.3 ms` | `436` |
| YOLOv8s | `640 x 640` | `2.4 ms` | `410` |
| YOLOv8m | `640 x 640` | `3.2 ms` | `316` |

## 4. 性能对比

| 模型 | FP32 平均耗时 | FP16 平均耗时 | 耗时下降 | FP32 FPS | FP16 FPS | FPS 提升 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| YOLOv8n | `2.6 ms` | `2.3 ms` | `11.5%` | `387` | `436` | `12.7%` |
| YOLOv8s | `3.3 ms` | `2.4 ms` | `27.3%` | `300` | `410` | `36.7%` |
| YOLOv8m | `4.9 ms` | `3.2 ms` | `34.7%` | `204` | `316` | `54.9%` |

## 5. 结论

- 在 `640 x 640` 输入尺寸下，YOLOv8n、YOLOv8s、YOLOv8m 均可完成毫秒级检测推理。
- FP16 相比 FP32 具有明显性能收益，模型越大收益越明显。
- YOLOv8n 具备最高吞吐率，适合对实时性要求更高的场景。
- YOLOv8m 推理耗时更高，但在 FP16 下仍可达到约 `316 FPS`。

## 6. 运行示例

可使用如下命令运行检测示例并输出性能指标：

```bash
./example/det/build/det_sdk_sample yolov8s.onnx imgs/bus.jpg config/det_config.json imgs/bus_res.jpg 5 50
```

参数说明：

| 参数位置 | 示例值 | 说明 |
| --- | --- | --- |
| 1 | `yolov8s.onnx` | 检测模型路径 |
| 2 | `imgs/bus.jpg` | 输入图片路径 |
| 3 | `config/det_config.json` | 检测配置文件路径 |
| 4 | `imgs/bus_res.jpg` | 检测结果图片保存路径 |
| 5 | `5` | 预热次数 |
| 6 | `50` | 性能统计次数 |
